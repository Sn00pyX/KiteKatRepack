Quick installation guide:
1) Download Miscrosoft SQL server (2022 or newer)
2) Install it (disable firewall before installing to avoid errors)
3) Install SSMS (Sql Server Management Studtio)
4) Log in using your windows login
5) Connect to your database engine
6) Restore databases: Right click to "Databases" -> "Restore Database..." -> Device -> Find a path to your .bak files (located in the "Backups" directory of the repack)
7) Do same for every database. You need Arcadia, Auth and Telecaster
8) Right click to "Security" -> "New" -> "Login"
9) Select "SQL authentication" and specify password. Check "Enforce password policy"; UNCHECK "Enforce password expiration"
10) During creation of new login, go to "User Mapping" in the same window (left side) and map it to all databases you restored with next permissions:
- db_accessadmin
- db_backupoperator
- db_datareader
- db_datawriter
- db_ddladmin
- db_owner
- db_securityadmin
11) Click "OK"; Create a user mapped to your databases
12) Encrypt user password using DESUtil (here is a guide how to do that)
13) Modify gameserver and authserver opt files. Change passsword/login values to ones you made. Password must be encrypted using DESUtil
14) Create an account (you can use account script I made)
15) Start auth server
16) Start gameserver
17) Log in the game using client
